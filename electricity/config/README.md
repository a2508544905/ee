# config/ 目录说明

本目录存放**配置文件**（不参与业务逻辑，运行时由 `lib/` 动态读取）。

| 文件           | 功能说明                                           |
| -------------- | -------------------------------------------------- |
| tariffs.json   | 各地区阶梯电价档位标准（档位边界 + 单价）           |
| users.json     | 预置用户名单（Excel 列号进位式：A,B,...,Z,AA,AB）   |
| anomaly.json   | 异常用电检测阈值（超高/环比暴涨暴跌/远超均值倍数）  |

## 约定

- 配置类数据必须放在此处，由代码动态读取，**不得写死在源码中**
- `config/` 下的文件禁止 import `lib/` 的模块（保持单向依赖）
