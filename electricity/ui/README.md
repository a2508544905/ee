# ui/ 目录说明

本目录存放 **tkinter 界面层代码**。负责收集输入、展示结果、编排业务流程；**不承载业务逻辑**（业务在 `lib/`）。

| 文件            | 功能说明                                       |
| --------------- | ---------------------------------------------- |
| main_window.py  | 主窗口：组装各面板、编排「计算/导入/导出/筛选」流程 |
| input_panel.py  | 输入区（用户名搜索 / 月份 / 地区 / 用电量 / 计算按钮） |
| result_panel.py | 结果概览卡片（总电费/档位/到下一档距离）        |
| record_table.py | 记录表格（Treeview）与筛选栏                    |
| more_panel.py   | 侧边功能（CSV导入/导出/统计图表入口）           |
| tariff_panel.py | 档位规则管理窗口                                |
| chart_view.py   | 图表窗口（嵌入 lib/chart_generator 生成的 Figure） |
| theme.py        | 暗色科技风主题配色                              |

## 约定

- `ui/` 可调用 `lib/`，但 `lib/` 不得反向依赖 `ui/`
- 界面代码只做展示与编排，计算、导入、统计等逻辑一律调用 `lib/`
