# ⚡ 阶梯电价可视化计算与查询系统

**输入即得 · 分档透明 · 图说电费**

基于 Python 桌面端，将阶梯电费计算从"查表手算"变为"输入即得"

</div>

---

## 📖 项目简介

本项目是一个基于 Python 桌面端的阶梯电价可视化计算与查询系统，面向需要频繁进行阶梯电费计算、对比和查询的场景。用户输入用电量即可自动按档位分段计算电费，并通过图表直观展示分档结果、临界点位置和历史趋势。

> **核心理念**：让档位本身成为思考单位——不是给一个总价，而是拆开告诉你钱从哪来、多用了会怎样。

---

## ✨ 主要功能

### 核心计算

| 功能 | 说明 |
|------|------|
| 🔢 **电费计算引擎** | 输入用电量，自动按阶梯三档（或自定义档位）分段计算，输出每档用电量、单价、小计金额及合计 |
| ⚠️ **临界点提示** | 输入值接近档位边界时，提示距下一档的差额及单价变化幅度，辅助用电决策 |
| ⚙️ **档位标准管理** | 预置多个地区阶梯电价标准，支持增删改查，政策调整时可直接修改 |

### 可视化展示

| 功能 | 说明 |
|------|------|
| 📊 **阶梯面积图** | 横轴用电量、纵轴电费，渐变色填充各档区域，竖线标注当前位置，一眼看出落在哪档 |
| 📈 **对比分析** | 不同用电量横向对比、不同地区同用电量对比，直观展示电费差异 |
| 📉 **账单趋势图** | 多月电费趋势折线图，背景色带标示档位区间，趋势走向一目了然 |

### 查询与管理

| 功能 | 说明 |
|------|------|
| 🗂️ **历史记录** | 保存每次计算记录，支持按时间、地区、用电量范围筛选查询 |
| 📋 **批量计算** | 从 Excel/CSV 文件导入用电量列表，批量计算并导出结果 |
| 💰 **电费估算器** | 输入预算金额，反推可使用电量上限 |

## 🚀 安装与运行

### 环境要求

- ✅ Python 3.8 及以上
- ✅ Windows / macOS / Linux

### 1️⃣ 安装依赖

```bash
pip install matplotlib openpyxl
```

> 💡 tkinter 为 Python 标准库，无需额外安装。

### 2️⃣ 运行程序

```bash
python main.py
```

### 3️⃣ 打包为可执行文件（可选）

```bash
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```

> 打包后可在 `dist/` 目录下找到可执行文件，分发给无需安装 Python 的用户。
